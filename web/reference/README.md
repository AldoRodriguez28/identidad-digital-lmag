# Referencia visual — sitio original

Material del sitio de referencia (https://tjuventud.epsomsegura.com/) para clonar su
UI/UX. Sirve para extraer paleta, tipografía, espaciado, radios y estructura de
componentes, y construir el sistema de diseño del clon.

> Nota: este material es de un sitio de terceros y **no se committea** (ver `.gitignore`
> en esta carpeta); solo se versiona este README. Es de uso interno como referencia.

## Dónde guardar cada cosa

- `screenshots/` — capturas de pantalla (PNG/JPG) de las pantallas ya logueadas.
  Nombra con la pantalla, p. ej.:
  - `login.png`
  - `dashboard-joven.png`
  - `credencial.png`
  - `mis-puntos.png`
  - `eventos.png`
  - `beneficios.png`
  - `panel-admin.png`
  (Móvil y escritorio si puedes: `credencial-movil.png`, `credencial-desktop.png`.)

- `pages/` — páginas guardadas completas: en el navegador, clic derecho →
  "Guardar como…" → **"Página web, completa"**. Deja aquí el `.html` y su carpeta de
  assets. Da los colores/fuentes/clases exactos.

- `css/` — si prefieres solo el CSS: en DevTools → Network → filtro **CSS** → guarda el
  archivo `.css` principal aquí.

## Prioridad para empezar
Con estas 3 ya puedo definir el sistema de diseño base:
1. `login`
2. `credencial`
3. `mis-puntos` (o `dashboard-joven`)

Cuando dejes los archivos, avísame ("listo") y los reviso desde aquí.
